# dashboard-nextjs

Next.js 15 (App Router) dashboard for the job tracker: kanban, funnel, days-per-stage and reply-rate metrics.

It runs in two modes, switched by one environment variable:

| | `DEMO_MODE=true` (public demo) | `DEMO_MODE` unset (private mode, v1) |
|---|---|---|
| Login | None | Password → HMAC-signed cookie (`middleware.js`, `lib/auth.js`) |
| Data | Fictional, generated by `lib/demoData.js` | Google Sheet via the Apps Script API |
| Writes | `localStorage` in the visitor's browser | `PATCH /api/jobs/[jobId]` → Apps Script |
| `/api/*` routes | Disabled (404) | Server-side proxy; the token never reaches the browser |

## Run locally

```bash
npm install
cp .env.local.example .env.local   # DEMO_MODE=true is already set
npm run dev                        # http://localhost:3000
npm test                           # metric unit tests (node:test)
npm run build
```

## Private mode

Set these in `.env.local` or in Vercel → Project Settings → Environment Variables, and remove `DEMO_MODE`:

- `APPS_SCRIPT_URL`: the `/exec` URL of the v1 Apps Script web app ([original-copilot/apps-script-v1/Code.gs](../original-copilot/apps-script-v1/Code.gs), which includes the `list` action).
- `APPS_SCRIPT_TOKEN`: the shared token stored in that script's properties.
- `DASHBOARD_PASSWORD`: the dashboard password.
- `SESSION_SECRET`: 16+ random characters to sign the session cookie. Without it, nobody can log in (fails closed).

## Where things live

```
app/page.js              server component: reads DEMO_MODE, renders <Dashboard>
components/Dashboard.js  data loading (demo store or /api/jobs), optimistic updates
components/FunnelPanel   funnel + average days per stage
lib/metrics.js           metric definitions (see ../docs/metrics.md) + metrics.test.mjs
lib/demoData.js          deterministic fictional data with an event history
lib/appsScript.js        the only file that knows the Apps Script token (server only)
middleware.js            auth gate, or open access + disabled API in demo mode
```

## Deploy on Vercel

New project → import this repo → **Root Directory: `dashboard-nextjs`** → environment variable `DEMO_MODE=true` → Deploy.
